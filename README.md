# Susanne Dahesh - Portfolio

En responsiv portfolio för Susanne Dahesh, frontendutvecklare i Helsingborg.
Sidan presenterar kompetens, erfarenhet, utvalda projekt och kontaktuppgifter.

## Teknik

- React
- TypeScript
- Vite
- CSS

## Innehåll

- Presentation och kontaktvägar
- Kompetens inom frontendutveckling och UI/UX
- Projekt med länkar till live-demos och GitHub
- Animerade projektförhandsvisningar vid hover
- Responsiv layout för mobil och desktop

## Kom igång

Kräver Node.js 18 eller senare.

```bash
npm install
npm run dev
```

Vite visar sedan en lokal URL i terminalen, vanligtvis `http://localhost:5173`.

## Tillgängliga kommandon

| Kommando | Beskrivning |
| --- | --- |
| `npm run dev` | Startar en lokal utvecklingsserver. |
| `npm run build` | Typsäkrar och bygger en produktionsversion i `dist/`. |
| `npm run preview` | Förhandsvisar den byggda produktionsversionen lokalt. |

## Projektstruktur

```text
src/
	App.tsx       Huvudinnehåll för portfolion
	main.tsx      React-applikationens startpunkt
	styles.css    Layout, färger och responsiva stilar
public/
	profile-new.jpg    Profilbild
```
